# A Brute-force Approach to the Job-Shop Scheduling Problem (JSSP)

## Running the Program

From the project directory:

```
python main.py
```

The problem instance is defined in `main.py`, including definitions for `K` and `jobs`

The brute force algorithm is implemented in `jssp.py`

## Notes

The implementation is based on an implementation of Giffler and Thompson's algorithm for the generation of active schedules.
